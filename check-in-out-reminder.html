Yes, Tamam includes notification features to help employees remember to check in and out.

Reminder Types

Check-In Reminders

  • Notification at the start of work shift
  • Reminder if employee hasn't checked in by a certain time
  • Late arrival alerts
  • Optional push notifications on mobile app

Check-Out Reminders

  • Notification near end of work shift
  • Reminder if employee forgets to check out
  • Alerts for overtime situations

Configuring Reminders

Administrators can set up reminders by:

  • Defining reminder times (e.g., 15 minutes before shift start/end)
  • Choosing notification methods (push, SMS, email)
  • Enabling/disabling reminders by department or role
  • Setting frequency and repetition rules

Employee Notification Settings

Employees can customize notifications:

  • Enable or disable reminders
  • Choose notification methods (app, SMS, email)
  • Adjust reminder timing preferences
  • Set quiet hours for notifications

Benefits

  • Reduces accidental check-out failures
  • Improves attendance accuracy
  • Helps maintain consistent work schedules
  • Prevents attendance disputes

Tip: Enable reminders if you tend to forget checking out at the end of the day.
