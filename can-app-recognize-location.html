Yes, Tamam uses GPS technology to verify that employees are at authorized work locations when they check in.

How Location Recognition Works

When an employee checks in:

  • The Tamam app captures the device's GPS location
  • The location is compared against authorized work locations
  • If the employee is within the defined radius, check-in is allowed
  • If outside the radius, check-in may be rejected or flagged

Location Requirements

  • GPS must be enabled on the employee's mobile device
  • The device must have a clear signal and internet connection for verification
  • Location accuracy is typically within 5-15 meters using modern GPS

Authorized Work Locations

Administrators configure work locations with:

  • Geographic coordinates (latitude and longitude)
  • A radius boundary (typically 100-500 meters)
  • Location name and description

Multiple Locations

If an employee works at multiple locations:

  • Each location is added as a separate authorized zone
  • Employees can check in at any authorized location
  • The system records which location each check-in occurred at

Tip: Keep GPS enabled during work hours for accurate location-based check-ins.
