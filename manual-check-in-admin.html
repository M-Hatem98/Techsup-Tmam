Can I check in an employee manually via the admin portal?

Yes, administrators can manually check in employees through the admin portal for special circumstances, emergency situations, or when normal check-in is not possible.

When to Use Manual Check-In

  • Employee's mobile device is lost or damaged
  • Technical issues preventing app-based check-in
  • Employee working in area with poor connectivity
  • Forgotten device or forgotten phone
  • Last-minute shift assignments

How to Manually Check In

  1. Log in to the Tamam admin portal
  2. Navigate to Employee Management or Quick Check-In
  3. Search for the employee by name or ID
  4. Click "Manual Check-In" or "Register Attendance"
  5. Enter check-in time and location
  6. Add optional notes or reason
  7. Confirm and save the manual check-in

Important Requirements

  • Only authorized administrators can perform manual check-ins
  • All manual check-ins are logged and auditable
  • Reason or justification should be documented
  • System records who made the manual entry and when
  • Manager notifications may be required depending on policy

Manual Check-In Features

  • Set custom check-in date and time
  • Select employee location
  • Add notes or comments
  • Optionally record check-out time
  • Configure working hours for that day

Best Practices

  • Use manual check-in as exception, not rule
  • Always document the reason for manual entry
  • Verify employee information before confirming
  • Review audit logs for anomalies
  • Limit manual check-in permissions to trusted admins

Tip: Contact your administrator if you need a manual check-in for legitimate reasons.
