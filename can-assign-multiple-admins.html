Yes, Tamam allows you to assign multiple administrators to manage the system and share administrative responsibilities.

Multiple Admin Benefits

  • Distribute administrative workload across team members
  • Provide backup administration if the primary admin is unavailable
  • Allow specialized admin roles for different functions
  • Enable delegated management for large organizations
  • Maintain audit trails of who made system changes

Admin Roles and Permissions

Tamam typically supports multiple admin levels:

  • Super Admin: Full system access and configuration
  • Admin: Core administrative functions
  • HR Admin: HR and reporting focused access
  • Department Admin: Limited to specific departments
  • Location Manager: Manages specific locations

How to Add Multiple Admins

  1. Go to the User Management section
  2. Create or select user accounts
  3. Assign appropriate admin roles
  4. Configure role-specific permissions
  5. Save and activate the new admin accounts

Considerations

  • More admins can speed up operations
  • Ensure proper permission levels to maintain security
  • Monitor admin activity through audit logs
  • Regularly review and update admin access

Tip: Assign specific roles based on job responsibilities to maintain security and reduce errors.
