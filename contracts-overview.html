Employee contracts are the foundation of payroll management. This guide covers managing contracts, contract types, salary components, and salary structure in Tamam.

Contract Management

The Contracts section allows you to:

  • View all employee contracts
  • Create new contracts for new hires
  • Edit existing contracts
  • Track contract start and end dates
  • Store contract documents and attachments
  • Manage contract renewal dates
  • Archive expired contracts

Contract List

The Contract List provides a centralized view of all employee contracts:

  • Employee name and ID
  • Contract type (permanent, temporary, fixed-term)
  • Contract start date
  • Contract end date (if applicable)
  • Contract status (active, expired, pending)
  • Renewal dates and reminders

Salary Types

Salary Types define different compensation structures:

  • Fixed salary
  • Variable salary
  • Commission-based
  • Hourly rate
  • Daily rate
  • Piece-rate (per unit)

Salary Components

Salary Components are individual elements that make up an employee's total compensation:

  • Earnings: Basic salary, allowances, bonuses, overtime pay
  • Deductions: Taxes, insurance, loans, social security
  • Reimbursements: Travel, meals, training expenses
  • Benefits: Health insurance, retirement contributions

Setting Up Salary Components

  1. Go to Contracts → Salary Component
  2. Click "Add New Component"
  3. Enter component name (e.g., "Basic Salary", "Housing Allowance")
  4. Select component type (earning/deduction/reimbursement)
  5. Enter component amount or percentage
  6. Set calculation basis (fixed/percentage/formula)
  7. Configure tax treatment
  8. Save the component

Best Practices

  • Regularly review and update salary components
  • Ensure component names are clear and descriptive
  • Document all deductions and their purposes
  • Keep salary structures aligned with labor laws
  • Review contracts before renewal dates
  • Archive expired contracts for record-keeping
