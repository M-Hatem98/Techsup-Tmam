Yes, Tamam provides real-time attendance status updates for all users within the system.

Real-Time Updates

When an employee checks in or out:

  • The check-in/out is immediately recorded in the system
  • Managers can see the status instantly on their dashboard
  • Notifications are sent to relevant stakeholders
  • Reports are updated in real time

Who Sees Real-Time Data

  • Employees: Can see their own status and history
  • Managers: See their team's real-time attendance status
  • Administrators: See organization-wide real-time status

Dashboard Updates

Real-time features include:

  • Live team attendance dashboard
  • Current present/absent employee count
  • Late arrival alerts
  • Instant notifications for approvals and requests
  • Real-time report generation

Internet Connectivity

Real-time updates require:

  • Active internet connection on the mobile app
  • System server connectivity
  • Regular page refresh for web portal users

Tip: Refresh your dashboard periodically to ensure you're viewing the latest attendance data.
