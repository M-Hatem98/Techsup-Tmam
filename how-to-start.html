How to use the system in simple steps

Start by creating the main setup items, then assign them to employees and begin using Tamam for daily attendance and management.

Use this onboarding workflow to set up the system correctly before beginning daily attendance operations.

01

Create Branches

Create your branches first so every team and attendance record is organized by the right workplace.

02

Create Department

Create departments to organize employees by team, section, or operating unit before assigning staff.

03

Create Categories

Create categories to classify employees, departments, or related records for easier management and reporting.

04

Create Locations

Create locations so the system can link employees and attendance actions to the correct work sites.

05

Create Shift

Define your work shifts so employees have clear attendance schedules and shift-based policies.

06

Create Roles

Create roles to control permissions, access levels, and what each user can manage inside the system.

07

Create Tasks

Create tasks so teams can assign work items, actions, and operational responsibilities in a structured way.

08

Create Holidays

Create holidays and leave calendars to keep attendance and payroll rules aligned with official company days off.

09

Then the user can use the system

Once the setup is completed in the correct order, employees and managers can start using Tamam for daily attendance, requests, approvals, and reports.
