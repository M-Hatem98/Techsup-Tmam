Start by creating the main setup items, then assign them to employees and begin using Tamam for daily attendance and management.

Use this onboarding workflow to set up the system correctly before beginning daily attendance operations.

01

Create Shift

Create your work shifts first so employees know their expected working hours and attendance rules.

02

Create Branch

Add each branch or location where employees work so attendance records can be grouped and managed properly.

03

Create Department

Create departments to organize employees by team, section, or operating unit before starting assignments.

04

Create Employee

Add employee records with the required information so they can be linked to the correct settings and permissions.

05

Assignment shift branch department

Assign every employee to the right shift, branch, and department so the system can calculate attendance accurately.

06

Then use the system

Once the setup is completed, employees can begin using Tamam for check-in, check-out, requests, approvals, and reports.
