Grouping employees makes it easier to manage schedules and apply policies to teams.

Step 1: Go to Employee Groups

Access the Groups or Employee Groups section from the admin navigation.

Step 2: Add a new group

Click Create Group, then enter a group name and optional description.

Step 3: Select employees

Choose the employees who should belong to the group and add them to the list.

Step 4: Review membership

Confirm the employee list is correct before saving the group.

Step 5: Save and use the group

Save the group so it can be used in reports, policies, and permissions.

Tip: Use groups for project teams, departments, or common work schedules to speed up reporting.
