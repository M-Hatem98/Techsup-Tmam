Yes, Tamam fully supports multiple work locations for organizations with distributed offices, branches, or field operations.

Multi-Location Benefits

  • Track attendance across all office locations
  • Assign employees to specific locations or multiple locations
  • Generate location-specific reports
  • Manage location-based attendance policies
  • Support remote and hybrid work arrangements

How to Add Locations

  1. Go to Settings → Locations Management
  2. Click "Add New Location"
  3. Enter location name and address
  4. Set GPS coordinates (latitude and longitude)
  5. Define the location radius
  6. Assign working hours and policies
  7. Save and activate the location

Assigning Employees to Locations

You can:

  • Assign employees to a single primary location
  • Allow employees to work at multiple locations
  • Set location-specific schedules
  • Configure which locations each employee can access

Location Management Features

  • Edit or delete locations as needed
  • Manage location-specific policies and shifts
  • Generate reports filtered by location
  • Track attendance rates by location
  • Monitor staff presence at each location in real time

Tip: Use descriptive location names and ensure accurate GPS coordinates for reliable check-ins.
